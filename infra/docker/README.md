# Infraestrutura local

Área reservada à configuração Docker Compose do ambiente de desenvolvimento, inicialmente com MySQL e, se necessário, os serviços da API.

Na Sprint 2, registrar versões, portas, volume persistente, healthcheck, variáveis de ambiente e comandos de inicialização/encerramento. Senhas locais não devem ser versionadas; manter somente um arquivo de exemplo sem segredos.
