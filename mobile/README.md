# Aplicativo mobile

Área reservada ao aplicativo React Native com Expo, TypeScript e Expo Router.

**Sprint 2:** inicializar o aplicativo, confirmar a execução em Android ou emulador e criar a estrutura base de rotas, componentes, tipos e serviços. A implementação das funcionalidades ocorrerá de forma incremental nas sprints seguintes.

O protótipo Figma é uma referência de navegação e interface; não é uma aplicação funcional nem uma fonte de dados reais.
